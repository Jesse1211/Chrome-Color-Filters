# 已知既有 flake:`docs/T7-gate/csp-fidelity.cjs` 的 N1 条款

**与本次「锁定 UI 折叠」改动无关,但为免后人误判,记录在此。**

## 现象

该门禁的最后一组里有一条:

> 🔴 N1:0 档是恒等变换 —— 同一页面上「0 档」与「无滤镜」的截图**逐字节相同**

它在**真实 wikipedia 页面**上连拍两张截图并 `Buffer.compare` 逐字节比对。
两张之间页面仍在活动(懒加载图片、动画、光标),于是偶发地差几个字节。

## 实测的翻动率(同一台机器,同一时段,各跑 4 次)

| 分支 | 通过 | 失败 |
|---|---|---|
| `main`(**未改动任何代码**) | 1 | 3 |
| `feat/lock-subpage`(本次改动) | 3 | 1 |

**基线 main 上失败得更频繁。** 这条条款不触及任何锁定 / popup 代码 ——
它只看 `filter.css` 的 `html[data-ccf-off]` 压制路径与页面像素。

失败时的 detail 也佐证了这一点:两张截图的像素统计量**完全相同**
(`spreadWithFilter: 178` / `spreadWithout: 178`),只有字节不同 ——
即滤镜确实是恒等变换,差异来自页面自身的重绘。

## 没有顺手「修」它的理由

把它改成「允许 N 字节差异」或换成像素统计比对,都是在**放宽一条既有断言**,
而本次任务明确禁止为了绿灯削弱门禁。该条款的加固(例如冻结动画、
改用本地固定页面)属于独立的门禁改进,应当单独立项、单独评审,
不该夹带在一次 UI 布局改动里。
