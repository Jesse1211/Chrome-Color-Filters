# T6c-gate · 锁定 UI 折叠改造(真实 Chrome)

## 这个门禁验什么

产品负责人的原话:

> 我要把「专注锁定」这里面的所有信息折叠起来,就显示「添加规则」一样,
> 用户需要点击一个「时间锁定」然后跳转页面,来设置时间。

以及他随后的两条补充决定:

- **倒计时留在列表页** —— 剩余时间是用户打开 popup 最想知道的那一个数;
- **「延长」搬进子页面** —— 点倒计时条进去。

`lock-subpage.cjs` 在**真实 Chrome + 真实扩展 + 真实 `chrome.storage.local`**
上端到端验证改版后的产品形态,**30 条**:

| 组 | 覆盖 |
|---|---|
| C1 | 列表页真的折叠成一行;内联时长选择器 / 预设 / 启动按钮全部不在场;列表页零数字输入零下拉 |
| C2 | 入口行是真 `<button>`、与「添加规则」共享 `.add-button` 基类、**键盘可聚焦且回车可触发** |
| C3 | 子页面形态(标题 / 返回 / 预设 / 数字 + 单位 / 启动);ADR-058 不接受裸时间戳;**I2 子页面无预览通道**;返回键可用且 **ADR-061 导航零写入**;ADR-052 未锁定时「只能延长,不能提前结束」的告知必须在场且只是文案 |
| C4 | ADR-056 二次确认(出现、三条后果逐条、取消零写入、焦点落在取消);**ADR-057 主开关 OFF → 启动后自动 ON**;启动端到端落盘 |
| C5 | 锁定中子页面换成延长形态;**列表页仍显示倒计时**;列表页无延长控件、无折叠入口;ADR-051 全禁用;**点倒计时条 → 延长成功**(lockUntil 严格 +3 分钟);两页同源 |
| C6 | 🔴🔴 **缩短 / 取消 / 解除在两页的可见文本与无障碍名里都不存在**;锁定中子页面只有「返回 + 延长」两个按钮;**「返回」不是「解除」**;**探针有效性**(注入一个「解除锁定」按钮,同一组扫描必须当场报违规) |

## 与 `docs/T7-gate/lock-e2e.cjs` 的分工

T7 那条验**锁定语义**(INV-11/12/13/14 + 跨重启 + 自然到期),它已随本次改版
更新了导航步骤(多一次点击),**一条断言都没删**,条款数 39 → 49。

本文件验**改版本身的产品形态**,不重复等那 60 秒的自然到期。

## 怎么跑

```sh
npm run build                          # 产物在 build/chrome-mv3/
node docs/T7-gate/build-probe.mjs      # 每次 build 之后都要重建探针
export NODE_PATH=<puppeteer 所在的 node_modules>
node docs/T6c-gate/lock-subpage.cjs
```

证据(截图 + JSON)落在 `docs/T6c-gate/out/`。
